## Supported use versus non-activated components

- **Host entry points:** Codex `$kaos`; Antigravity `/kaos`; Claude Code source-package entry point `/kaos:conductor`. Packaging and source validation are not proof of live activation on each host. Follow [installation](../../setup/INSTALLATION.md) and [compatibility](../../setup/COMPATIBILITY.md).
- **Not newly qualified:** live JEV/TypeSafe inference, general BYOK onboarding, trusted R3-A host identity, automatic live capability discovery and private-memory promotion, effectful Cipher inference/audits, unsupported IDE adapters, and production/deployment authority.
- **License and data boundaries:** The repository source is MIT-licensed subject to applicable third-party notices. Kaos v1.12.0 is not an owner-operated hosted service. User-selected hosts/providers have separate data handling; optional local A1/A2/A3 records may persist when invoked. The linked privacy/terms documents are drafts, not approved standalone policies.
